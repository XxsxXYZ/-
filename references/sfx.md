# 音效与卡点设计

## 一、"卡点"到底是什么

**口播念到某个词的那一帧 = 画面元素出现的帧 = 音效响起的帧。**
三者误差 ≤ 3 帧（0.1 秒）。

```
口播说到"听"
   ↓ 同一帧
画面元素弹入（入场动画 0.3 秒）
   ↓ 提前 0.05 秒
音效响起
```

**术语**：这个做法叫「口播卡点」（英文 Word-Synced Animation）。
底层技术支持叫「词级时间戳」（Word-Level Timestamps）。
通用技法名是「动态排版 / Kinetic Typography」。

---

## 二、音量结构（这是"听着舒不舒服"的关键）

| 轨 | 建议电平 | 说明 |
|---|---|---|
| 人声 | **−25 dB** | 主体 |
| 音效 | **−18 ~ −22 dB** | 比人声低一点，比 BGM 高很多 |
| BGM | **−40 dB** | 感觉有音乐，但听不清音乐 |

人和 BGM 差 **15 dB**。这是"专业"和"吵"的分界线。
新手常把 BGM 推到 −20 dB 附近，结果就是全程轰。

---

## 三、密度（超过就是噪音）

| 类型 | 密度 | 说明 |
|---|---|---|
| 短音效 | **每 3–4 秒一个** | 0.15–0.4 秒 |
| 重音效 | 每 15–20 秒一个 | 0.5–0.8 秒，用在换段/揭示 |
| 时长 | 短音效不要超过 0.4 秒 | 拖长的音效会糊 |

**参考实测**：一条 177 秒的爆款，独立插入式音效总共只有约 11 个可疑事件（平均 16 秒一个），节奏感主要来自**人声的语速和断句**，不是音效。

> 但这不代表你该少加。**理性内容靠人声节奏就够；文化/神话题材需要声音建立氛围**（药碾、翻书、铜铃、陶器）。**按题材定密度，不按模板定。**

## 四、8 种基础音效（可用代码合成，无版权风险）

| 音效 | 音色 | 用在哪 |
|---|---|---|
| `tick` | 短促"嗒" | 文字逐字出现 |
| `pop` | 上滑"啵" | 卡片/图标弹入 |
| `ding` | 清亮"叮" | 光圈、强调 |
| `stamp` | 低频"咚" | 印章盖下、结论 |
| `whoosh` | 风声 | 转场、甩镜 |
| `swish` | 轻擦 | 贴图飞入 |
| `bell` | 铜铃 | 段落切换 |
| `hmm` | 低沉"嗯" | 角色反应 |

合成思路（声音本质是空气振动，既然是数字就能算）：
- 一个音 = 正弦波 `sin(2π·f·t)`
- 底鼓 = 低频 + 快速指数衰减
- 铜铃 = 多个泛音 + 长衰减
- 锣镲 = 白噪声 × 长衰减

## 五、有口播时的三条特殊规则

1. **人声优先。** 说话时音乐和音效要让位——整片会安静很多，但听得清。
2. **音效避开关键词和句首。** 音效落在关键词上会盖住人声。
3. **不要在句首加"叮"。** 句首是观众接收信息的时刻，任何声音都是干扰。

## 六、卡点表怎么写

| 口播触发词 | 画面元素 | 音效 | 音量 |
|---|---|---|---|
| "真的只是**听**吗" | 光圈套住"闻" | `ding` | −20 |
| "**不专主于听声也**" | 朱砂框圈住原句 | `stamp` | −16 |
| "一是**听**" | 耳朵图标 | `swish` | −22 |
| "**臊、焦、香、腥、腐**" | 五字依次蹦入 | `ding` ×5（音高递进） | −20 |
| "**把鼻子交给了仪器**" | 鼻子 → 箭头 → 仪器 | `swish` | −20 |

**技术实现**：所有音效的时间点写进 `timeline.js` 的 `CUES`，画面和 `score.mjs` 都从这里 import。
这样画面和声音读的是同一张表，不需要手动对齐。
