# 明令禁止清单（硬规则，违反即返工）

> 来源：用户在本项目中逐条提出过的禁止项、纠正过的错误、以及引擎/平台的硬性限制。
> **一条都不许省略。没有"这次例外"。**

---

## 一、内容真实性（用户最在意）

| # | 禁止 | 正确做法 | 本项目实例 |
|---|---|---|---|
| 1 | **编造历史医案 / 名人故事** | 用真实文献记载；戏剧化场面必须旁白声明"说个场面" | 用户曾说"可以自己编"，拒绝，改用教材「病室气味」+ 现代医学 |
| 2 | **断言没查证的年份** | 查不到就不说 | 1808 是**王孟英出生年**，不是《重庆堂随笔》成书年，不许写"1808 年成书" |
| 3 | **把声旁说成形旁/象形** | 查《说文》原句 | 「闻」= 从耳，**门声**。「门」是声旁，不是"站在门口" |
| 4 | **凭印象描述古文字形** | 查甲骨文字形 | 甲骨文「闻」= **一个人跪坐、手搭在耳朵上**，不是"门里一个耳朵" |
| 5 | **编百分比** | 无据即删 | "九成人不知道"→ 禁用 |
| 6 | **编"我有个朋友"的案例** | 用文献或公开病例 | — |
| 7 | **前后自相矛盾** | 写完通读一遍查逻辑 | 曾写「门里头一个耳朵」5 秒后又说「门不是门口」，被用户指出必改 |
| 8 | **把已查证的事实说成"后来才有的"** | 核实最早出处 | 「闻」管气味不是清代才有，《素问》早有五臭 |

## 二、视觉（用户截图指出过的）

| # | 禁止 | 正确做法 |
|---|---|---|
| 9 | **手画人体器官**（耳/鼻/眼/嘴） | 用 3D emoji 或真 3D 素材。手画必然透视错、比例错、认不出 |
| 10 | **扁平黑描边线稿当图标** | 参考片是"**3D 软陶图标 + 扁平描边卡**"两层，图标层不能有黑描边 |
| 11 | **红圈/黄圈套住关键词** | **关键词直接变红**（黑字→红字），圈会压字 |
| 12 | **两个元素共用一个 y 坐标** | 同级元素必须分层留距；交付前逐帧核 |
| 13 | **元素只出现不退场** | 一拍一幕：当前拍淡入、上一拍淡出 |
| 14 | **一屏塞多个信息点** | 同一时刻只让观众看一样东西 |
| 15 | **深色背景 + 紫蓝渐变发光** | 米白纸张 + 圆点网格 |
| 16 | **超过 6 种颜色 / 超过 1 种字体** | 六色定死，一种粗黑体 |
| 17 | **设置 background / color / background-color 等颜色 CSS** | 卡片和页面禁止自定义颜色样式 |
| 18 | **弹窗**（alert / confirm / prompt / 弹窗组件） | 一律禁止 |
| 19 | **杜撰图片地址和链接 URL** | 只能用真实存在的；没有就代码画 |
| 20 | **`children` 里放 JSExpression** | 用 `Text` 组件或 `loop` 渲染 |

## 三、动效（"PPT 感"的来源）

| # | 禁止 | 正确做法 |
|---|---|---|
| 21 | **把口播一句一句做成标题卡** | 这是最典型的失败："其实就是在翻 PPT" |
| 22 | **所有元素一起淡入** | 逐字卡点，卡在词上 |
| 23 | **匀速平移当动效** | 用 outBack / outCubic 缓动 |
| 24 | **按"第几秒"出厂** | 按"第几个字"出厂 |
| 25 | **段落硬切** | 好转场是"从上一个画面里长出来" |
| 26 | **一幅画面空白超过 1.5 秒** | 补标题/前导元素填补 |

## 四、音频

| # | 禁止 | 正确做法 |
|---|---|---|
| 27 | **用 hi-hat / clap / crash / riser / shaker 做知识片配乐** | 这些噪声类音色就是"沙沙"来源；改古琴拨弦 + 弦乐铺底 + 低频 |
| 28 | **`ffmpeg loudnorm` 用动态模式** | 会抬高频 7dB；用两遍法 + `linear=true` |
| 29 | **母带时长不等于 DUR** | `N = round(DUR*SR)`，build.sh 容差只有 1.5/fps |
| 30 | **BGM 和人声同音量** | 人声 0dB、配乐 −15dB |
| 31 | **音效压在关键词和句首** | 音效起点比元素出现早 0.05s，避开关键词 |

## 五、事实核查（每条片子必做）

- **A 档**：有原文 / 国标 / 权威机构 → 可以直说
- **B 档**：多来源交叉但未见原著 → 说"一般认为"
- **C 档**：查不到 → **删掉**，或明说"这个说法有争议"

> 查不到的东西不要为了"有反差"硬讲。**被评论区指出一次，这条片子就废了。**

---

## 六、合规红线（题材涉医健时）

- 不说"能治 / 可治 / 治愈 + 病名" → 改"古籍中记载…"
- 不说"降血压 / 抗癌 / 排毒" → 改可观察的生活化描述
- 不给剂量、方药、穴位处方
- 每片必带免责声明，**且要口播念出来**，不能只压小字
- 引用古籍原句，画面角标必须标**书名 + 篇名**

---

> 用户原话：**"你做完以后需要自行检查 有无出现bug自己先完成一次检查验收 再给我 你的图标你自己截屏来看"**

| 35 | 技术检查 `All technical checks passed` + 无闪帧 |
| 36 | 没有实际执行的动作不许说"已验证""已生效" |
