# 三遍验收（交付前必做）

> 用户原话：**"你做完以后需要自行检查 有无出现bug自己先完成一次检查验收 再给我 你的图标你自己截屏来看"**
>
> 三遍缺一遍都不许交付。

---

## 第一遍：改完立刻渲关键帧（30 秒）

**任何代码改动之后**，先渲 3–6 张静帧确认，**不要直接跑整片**。

```bash
node <engine>/scripts/render.mjs <slug> --still 22,25,28 --size 1080x1920 --sheet
```

- 整片 7367 帧 ≈ 4 分钟；静帧 6 张 ≈ 30 秒
- 特别检查：**改动的段落前后各一帧**（防止括号/变量错误导致整片崩）
- 用 `read_image` 亲眼看，不要只看退出码

### 必查项
| 项 | 怎么看 |
|---|---|
| 有没有报错 | `[pageerror]` / `ReferenceError` → 语法或变量问题 |
| 元素是否重叠 | 看字压字、图标压字 |
| 图标是否可辨认 | 耳朵像耳朵、鼻子像鼻子 |
| 有没有空屏 | 内容区应有元素 |
| 字幕和画面对不对 | 字幕在讲什么，画面就在演什么 |

## 第二遍：全片抽帧自检（3 分钟）

```bash
# 每 10 秒一帧拼成 5×5 总检图
ffmpeg -hide_banner -loglevel error -i out/final.mp4 \
  -vf "fps=1/9.82,scale=320:-1,tile=5x5" -frames:v 1 qa/FINAL_check.png -y
```

然后**逐格看这张图**。重点扫：
- 空白帧
- 文字重叠
- 图标被裁切
- 段落之间有没有突变

### 自动化辅助（可选）

```python
# 空屏检测：内容区非背景像素占比 < 0.004 判为空白
bg = np.array([245, 242, 234])
diff = np.abs(img[int(H*0.20):int(H*0.62)] - bg).sum(axis=2)
ink_ratio = (diff > 26).mean()
if ink_ratio < 0.004: 报告("BLANK")
```

> ⚠️ 注意：**"大面积纯色块"这个指标会误判**——纸感背景本身就是大面积纯色。
> 只保留"空屏"和"出血"两项自动检查，其余靠肉眼。

## 第三遍：引擎技术检查（自动）

```bash
FPS=30 SIZE=1080x1920 AUDIO=file AUDIO_FILE=audio/final.wav sh build.sh
```

必须看到：

```
flash frames ...: none
duration XXXs · −14.x LUFS · true peak −1.x dBFS
All technical checks passed.
```

### 判定标准

| 项 | 合格 |
|---|---|
| 时长 | 与 `DUR` 差 < 0.1s |
| 响度 | −14 ± 1 LUFS |
| 真峰值 | ≤ −1 dBTP |
| 闪帧 | `none` |
| 帧数 | `DUR × 30` |
| 音频 | AAC 有音轨 |

### 已知可接受的 WARN

| WARN | 为什么可以接受 |
|---|---|
| `thin: almost no low end` | 人声占 90% 音量、本身无低频，只要片子有人说话就会报。**只要配乐不是噪声铺底即可放过** |
| `harsh/hissy` | **不可接受**——出现说明高频有问题，去查 `01-pitfalls.md` C1 |

## 降本增效：这张表能省多少

| 做法 | 省下 |
|---|---|
| 先渲静帧再跑整片 | 每次返工省 **3.5 分钟** |
| TTS 分句缓存，只重录改动的句 | 改一句省 **3 分钟** |
| 两遍法排时间轴 | 省掉 **3–5 轮**时间轴返工 |
| 单段重渲 `--start/--duration` | 改一段从 4 分钟降到 **几十秒** |
| 补丁写成 `.py` 文件 | 省掉 PowerShell 引号调试 |
| 图像生成失败立刻改用 emoji | 省掉反复重试 |
| 先做 emoji 字形可用性测试 | 省掉"渲完才发现是空框" |
