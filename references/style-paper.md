# 纸感手账视觉系统（完整参数）

> 这是从一条已验证的知识片逐帧反推出来的设计系统。
> 核心结论：**只用 12 个零件，反复组装**。零件越少，成品越像"作品"。

---

## 0. 一句话

```
米白纸张 + 圆点网格  →  3D 软陶图标  →  Q版平涂角色  →  黑描边贴纸卡
```

四层，缺一层就不像。

## 2. 背景

```js
const C = {
  paper:  '#F5F2EA',   // 米白纸张
  dot:    'rgba(206,198,184,0.55)',
  ink:    '#1A1A1A',
  blue:   '#2E7BE8',
  yellow: '#FFC93C',
  green:  '#C8E6A8',
  pink:   '#F5C8C8',
  orange: '#F5D0A8',
  red:    '#D63434',
};
const DOT_GAP = 40 * U;   // 点距 40px（1080 宽里约 27 个点）
const DOT_R   = 2 * U;
```

圆点必须**很淡**。太密太深就成了格纹纸，立刻廉价。

四周加极淡暗角（vignette），让画面像"一张纸的边缘"。

## 5. 描边贴纸卡（核心零件）

```js
function stickerCard(ctx, x, y, w, h, fill, U) {
  const R = 16 * U, OW = 5 * U, OFF = 8 * U;
  // ① 硬投影：不模糊，偏移 8px，不透明度 28%
  ctx.fillStyle = 'rgba(0,0,0,0.28)';
  rr(ctx, x - w/2 + OFF, y - h/2 + OFF, w, h, R); ctx.fill();
  // ② 卡片主体 + 黑描边
  ctx.fillStyle = fill;
  rr(ctx, x - w/2, y - h/2, w, h, R); ctx.fill();
  ctx.strokeStyle = C.ink; ctx.lineWidth = OW;
  rr(ctx, x - w/2, y - h/2, w, h, R); ctx.stroke();
}
```

**关键：投影的模糊必须是 0。** 一旦模糊，就从"贴纸"变成"浮起来"，风格立刻散。

变体：
- **便利贴**：去掉描边，保留柔影（用于三卡并排）
- **气泡台词**：白底 + 黑描边 + 小尾巴三角形
- **印章**：红框 + 轻微旋转 + 缩放盖章入场

## 6. 3D 软陶图标

| 来源 | 说明 |
|---|---|
| 现成 3D emoji 包 | Fluent Emoji 3D（MIT 可商用），风格最统一 |
| AI 生成 | 提示词见下 |
| **不要** | 给 3D 图标加黑描边——黑描边只属于"卡片"，混了就没层次 |

**通用提示词骨架**
```
3D 软陶风格图标，[物体名]，磨砂黏土质感，圆润造型，左上方向打光，
柔和落地阴影，纯白背景，居中构图，单个物体，微立体，高清，无文字
```
三个关键词缺一不可：`软陶/磨砂黏土`、`圆润造型`、`左上方向打光`（光源一致才像同一套）。

**图标尺寸**：画布短边的 8%–14%。太大就土，太小看不见。

## 7. Q版角色（可选）

| 项 | 规格 |
|---|---|
| 画风 | 日系平涂，清晰色块，五官简洁 |
| 构图 | 半身/侧身，贴边裁切，**固定在一个角** |
| 表情 | 7 个就够：`^^` `><` `--` `(・_・)` `(>▽<)` 瞪眼 呆住 |
| 出现频率 | 每 8–10 秒一次，只在"观众会有情绪反应"的地方 |

**呼吸感**：缩放关键帧 100% → 101.5% → 100%，周期 2–3 秒。
**幅度必须极小。超过 3% 就变成抽动。**

---

## 8. 动效库（只用这 8 种）

| 动效 | 实现 | 用在哪 |
|---|---|---|
| **弹入** | 缩放 `easeOutBack`，0.3–0.4s | 所有元素出场 |
| **错峰** | 相邻元素延迟 0.3–0.5s | 三卡并排 |
| **划线** | 宽度/高度从 0 生长 | 否定、分隔 |
| **荧光笔** | 色块宽度从 0 → 1 | 关键词高亮 |
| **盖章** | 缩放 1.4→1 + 旋转 +12°→+5° | 结论、印章 |
| **光圈** | 圆形半径 0.7→1 + 淡入 | 强调某个字 |
| **生长** | 路径 stroke-dashoffset 递减 | 箭头、连线、描边动画 |
| **呼吸** | 缩放 100%→101.5% 循环 | 角色、常驻元素 |

**禁止**：所有元素同时淡入、匀速平移、无意义的粒子。

---

## 9. 转场（只用 3 种）

| 转场 | 用在哪 | 实现 |
|---|---|---|
| **黑场金芒卡** | 换章节 | 深蓝黑底 + 金色放射光 + 3D图标 + 超大白字冲击 |
| **圆形蒙版收缩** | 结束 | `ctx.arc` 裁剪半径 100%→0 |
| **甩镜** | 特殊标记 | 位移 + 子帧运动模糊 |

**同一个转场不要重复用在同级上。**

## 10. 字幕

```js
// 黑底 85% + 圆角 16 + 白粗体 + 关键词黄
subtitleStyle = {
  bg: 'rgba(0,0,0,0.85)', radius: 16*U,
  padX: 34*U, padY: 20*U,
  font: 'bold 44px', color: '#FFF',
  keywordColor: C.yellow,
  y: H * 0.735,
};
```
- 每句一行，不换行；一句话可以跨两个镜头
- **每句标黄 1–2 个关键词**，不要全标
- 一句停留 = 它的口播时长

## 11. 顶部进度条（常驻）

```
轨道：x 120→960，y 250，高 14，圆角 7，颜色 #D6D6D6
填充：同位置，蓝色渐变，宽度 = 全片进度
进度头：半径 14 的蓝色圆点，带一点光晕
```
成本极低（3 个图层），但承担了全片的"结构感"。

---

## 12. 常驻徽章（左上角）

黑底圆角矩形 +「第X级/第X章」黄字 +「炼气/筑基」白字。
全片只在一处变化：换章节时。
**这是"读者随时知道自己在哪"的锚点。**
