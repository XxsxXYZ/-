# 合规红线（中医 / 健康 / 医疗题材必读）

> 适用于抖音、视频号、小红书、B 站。
> 以下不构成法律意见，发布前请对照平台当期规则复核。

---

## 一、一句话原则

**讲「书里怎么记的」，不讲「你能怎么用」。**

一旦越过这条线，就从"文化科普"变成"医疗诊断宣称"，性质完全不同，处罚也不同。

---

## 二、高危词 → 安全改写对照表

| ❌ 禁用 | ✅ 改写 | 原因 |
|---|---|---|
| 能治 / 可治 / 治愈 / 根治 + 病名 | 古籍中记载"食之已 X" | 疗效宣称需资质 |
| 降血压 / 降血糖 / 抗癌 | 传统上认为……（不承诺结果） | 疗效承诺 |
| 高血压 / 糖尿病 / 失眠症 | XX 症状、XX 不适 | 病名 = 诊断范畴 |
| 吃 XX 多少克 / 几副 | 具体用量请遵医嘱 | 剂量 = 处方行为 |
| 排毒 / 祛湿 / 打通经络 | 换成可观察的生活化描述 | 无公认定义，易判虚假宣传 |
| 包好 / 百分百 / 立竿见影 | 删除 | 绝对化用语 |
| 偏方 / 神方 / 秘方 | 古籍记载的做法 | 敏感词 |
| 你也可以在家自测 | 删除 | 引导自我诊断 |
| 中医比仪器还准 | 中医的价值在于……但它代替不了化验 | 贬低现代医学 |
| 我有个朋友 / 我亲戚 | 删除，改用古籍、文献、历史故事 | 变相疗效证明 |
| 诊断 / 确诊 / 治疗 / 疗效 / 治愈率 | 判断 / 辨 / 古籍记载 | 《广告法》第 16/17 条 |

## 三、绝对禁止：编造数据

**"九成的人都猜错了""90% 的人不知道""99% 的人理解错了"——只要没有调查来源，一律禁用。**

一旦评论区问"哪来的九成"，你没有答案，这条片子就废了。

**替代方案：把"大众误解"换成"历史悬案"。**
同样有反差感，但每句都能落到原文上。

例：
> ❌ "九成人猜错了闻诊"
> ✅ "这个问题，连古人自己都吵过。直到清代中期才有人专门写文章拍板。"

---

## 四、三条结构性安全原则

1. **主语从"这个药"换成"这本书"**
   观众听到的是知识，不是医嘱。

2. **因果关系降级为陈述关系**
   - ❌ "XX 能治 XX"
   - ✅ "XX 文献里出现过 XX"

3. **每片必带免责声明**（口播念出来 + 字幕显示，双保险）
   > "以上是文献和教材里的记载，属于医学史知识，**不是诊疗建议**。身体不舒服，请去正规医院。"

---

## 五、引用古籍的技术规范

**凡引原句，画面角标必须标书名 + 篇名。**

例：`清·王学权《重庆堂随笔》卷下`

这不只是学术规范——也是平台判定"科普 vs 伪科普"的加分项，能显著降低被举报概率。

---

## 六、事实核查三档（发布前逐句标注）

| 档 | 条件 | 可以说成 |
|---|---|---|
| **A** | 有原文 / 国家标准 / 权威机构 | 直接陈述 |
| **B** | 多来源交叉一致，但未见原著 | "一般认为""通行教材里写" |
| **C** | 查不到 | **删除**，或明说"这个说法有争议" |

**C 档内容不要为了"有反差"而硬讲。** 被懂行的人一句话拆穿，账号信誉就没了。

---

## 七、容易忽略的一个坑：伪古文

AI 为了让文案"有古韵"，会编造听起来很古籍的句子。
**所有带引号的古文，必须能指向具体篇名，且亲手核过原文。** 核不到就改成"古人认为……"这种模糊表述。
