# 叙事骨架

## 1. 默认：阶梯式五段（已验证）

```
钩子（全片 10%，8–12 秒）
  └ 一个反常识事实 + 一个悬念问题
主体：3–5 个台阶
  └ 每个台阶严格走「四拍子」
收尾（全片 10%）
  └ 一句可执行的行动 + 一个系列钩子
```

## 2. 时长分配：前紧后松

| 段 | 占比 | 90 秒的话 |
|---|---|---|
| 钩子 | 10% | 9 秒 |
| 台阶 1 | 12% | 11 秒 |
| 台阶 2 | 18% | 16 秒 |
| 台阶 3 | 20% | 18 秒 |
| 台阶 4 | 22% | 20 秒 |
| 收尾 | 18% | 16 秒（含免责） |

**第一个台阶只给 12%**——对观众来说那是"已知"，讲多了浪费时间。

## 3. 每个台阶的「四拍子」

| 拍 | 内容 | 画面手法 |
|---|---|---|
| ① 定义 | 这个台阶是什么 | 标题卡 / 章节徽章切换 |
| ② **反例** | 大多数人以为的（错的） | 划掉、`≠`、红章、⛔ |
| ③ 正例 | 正确是什么 | 2–4 个元素逐个出现 |
| ④ **验证** | 怎么判断做到了 | 对勾、表格、"才叫"结论 |

> **干货感来自 ② 和 ④，不是 ③。**
> 观众记住的不是"你给了新知识"，是"你纠正了我原来的想法"。

## 4. 钩子的 6 种可用型号

| 型号 | 结构 | 例 |
|---|---|---|
| 引用反差 | 引原文 → 翻译成大白话 | 「书里有一句话反复出现：'食之已疠'。翻成大白话：吃了能治病。」 |
| 数量反差 | 一个出乎意料的数字 | 「这个问题，吵到 1808 年才有人拍板。」 |
| 认知纠偏 | 你以为 X，其实 Y | 「中医的'闻'，你以为只是听？」 |
| 结果倒置 | 先给结论，再讲为什么 | 「这条规矩，连古人都反对过。」 |
| 具体场景 | 一个能看见的画面 | 「古人会凑近病人的便器闻一闻。」 |
| 时间跨度 | 用年份制造重量 | 「从'只听'到'又听又闻'，走了两千年。」 |

**禁止**：「大家好」「今天我们来聊聊」「你知道吗」（无信息量的开场）。

## 5. 收尾的两种

| 型号 | 结构 |
|---|---|
| 行动型 | 「下次你看到 X，先看 Y」——给观众一个具体的动作 |
| 系列型 | 「下一期讲 Z」——用未闭合的问题留人 |

**两种都用最好：先行动，再系列钩。**

## 6. 视觉节奏（比文案节奏更容易被忽略）

- **不要一直动。** 全片运动中位值应该很低（大量时间画面近乎静止）。
- **靠元素逐个出现维持"活"。** 每 2–3 秒变一次，每次只变一个元素。
- **整屏替换（硬切）每 8–12 秒一次就够。**
- **大动作只出现在"换台阶"和"关键揭示"的那 1–2 秒。**

参考数据（一条 177 秒的爆款实测）：
```
画面运动能量中位值：1.33（满分 100）
硬切：约 16 次 / 177 秒 ≈ 每 11 秒一次
元素级变化：每 2 秒一次
```
